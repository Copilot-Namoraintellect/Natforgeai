## A3 — EXACT-ONCE / REPLAY: PASS

DB-unique natural key is the only dedup authority (no in-memory state).
Proven: duplicate delivery → one row; concurrent delivery → one row
(lost-race re-read verifies); crash-after-persist → retry returns existing;
out-of-order → safe (immutable rows); provider retry → no duplicate effect;

on replay; `observedAt`/`createdAt` correctly excluded (per-attempt metadata).
