# WBS-R2.3 — Production Configuration / Secrets Readiness Manifest

Built from the codebase (`api/lib/env.ts`, `api/boot.ts`, `api/lib/crypto.ts`,
`api/lib/integrations/platforms.ts`, `api/publishing-router.ts`,
`api/queries/connection.ts`, `drizzle.config.ts`, `vite.config.ts`).
**No secret values appear in this document or in the repository.** The
companion template `env.production.template` contains placeholders only.

Legend — **Req**: R = required for production boot (fail-closed), F = required
for the named function to work, O = optional/feature-gated, T = test/ops-only.
**Inf.**: can a value be inferred from the repo (defaults exist)?
**Manual**: must a human supply it (secret or environment-specific fact)?
