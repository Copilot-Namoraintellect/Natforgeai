- **Table parity:** `db/schema.ts` declares 47 tables; the terminal snapshot
  `meta/0026_snapshot.json` contains the same 47 tables. Zero tables in
  snapshot-but-not-schema, zero in schema-but-not-snapshot.

  corresponding `schema.ts` declaration (automated comparison; residual
  reported diffs were verified to be index/foreign-key-callback artifacts,
  not columns). No column exists only in the snapshot lineage or only in

  schema vs `0026_snapshot` and produce only a new forward migration (none
  was generated or executed, per constraints).
